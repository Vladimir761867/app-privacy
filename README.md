# app-privacy

Public privacy policies and support pages for Great Family Games apps, served by GitHub Pages at https://vladimir761867.github.io/app-privacy/.

| Game | Pages |
|---|---|
| Yard Football | `yard-football/` |
| Forzaryon (formerly Afterburn Skies) | `afterburn-skies/` |
| Monsters Ate My Rainbow! (formerly Победитель Junior) | `monsters-ate-my-rainbow/` |
| Sigh & Smash | `winner/` |
| Ephemera | `store-release-20261127/ephemera/` |
| Mopello’s World | `store-release-20261127/mopello/` |
| Рядом | `ryadom.html` |

Each game folder with a `docs/` subfolder is generated: edit `docs/content.json` or `docs/product.json`, then run `python3 <folder>/docs/generate.py`.

Old URLs (`football.html`, `afterburn.html`, `winner.html`, `winner-junior.html`, and the store-release copies of Forzaryon, Monsters and Sigh & Smash) redirect to the current pages, so links already in the stores keep working.
